# Data Governance

Solutions for implementing data governance, lineage, access controls, and compliance patterns on Databricks.

## Scope

This category covers:

- **Unity Catalog** - Catalog/schema setup, external locations, and storage credentials
- **Access Controls** - Table ACLs, row/column-level security, and dynamic views
- **Data Lineage** - Lineage tracking, impact analysis, and audit patterns
- **Data Quality** - Expectations, validation frameworks, and monitoring
- **Compliance** - Data classification, retention policies, and regulatory patterns

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on adding new projects to this category.

Each project should include:
- A dedicated README with setup and usage instructions
- Clear documentation of required Unity Catalog configurations
- Synthetic test data only (no customer data or PII)
