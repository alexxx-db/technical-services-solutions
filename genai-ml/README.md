# GenAI & ML

Solutions for machine learning and generative AI implementations on Databricks.

## Scope

This category covers:

- **Model Training** - MLflow experiments, distributed training, and hyperparameter tuning
- **Model Serving** - Model deployment, real-time and batch inference endpoints
- **Generative AI** - RAG pipelines, LLM fine-tuning, prompt engineering, and AI agents
- **Feature Engineering** - Feature Store patterns and feature pipelines
- **MLOps** - Model registry, CI/CD for ML, monitoring, and A/B testing patterns

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on adding new projects to this category.

Each project should include:
- A dedicated README with setup and usage instructions
- Sample notebooks with synthetic data
- Required compute and library configurations
- Model artifacts should use public/synthetic datasets only
