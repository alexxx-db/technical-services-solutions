# Data Warehousing

Solutions for building and optimizing data warehouses using Databricks SQL and the Lakehouse architecture.

## Scope

This category covers:

- **Databricks SQL** - SQL Warehouse configurations, query patterns, and performance tuning
- **Data Modeling** - Star schema, medallion architecture, and dimensional modeling patterns
- **Migration** - Migration scripts and patterns from legacy warehouses (Snowflake, Redshift, Synapse, BigQuery)
- **Performance** - Query optimization, Z-ordering, liquid clustering, and caching strategies
- **BI Integration** - Connectivity patterns for Tableau, Power BI, Looker, and other BI tools

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on adding new projects to this category.

Each project should include:
- A dedicated README with setup and usage instructions
- Sample SQL scripts with synthetic data
- Required SQL Warehouse configurations
