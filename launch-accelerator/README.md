# Launch Accelerator

Quick-start templates and accelerators for rapid Databricks onboarding and common implementation patterns.

## Scope

This category covers:

- **Quickstart Templates** - End-to-end project templates for common use cases
- **Onboarding Kits** - Getting-started guides and environment bootstrap scripts
- **Reference Architectures** - Complete architecture blueprints with implementation code
- **Assessment Tools** - Readiness assessments, environment validation, and health checks
- **Migration Accelerators** - Tools and scripts to speed up platform migrations

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on adding new projects to this category.

Each project should include:
- A dedicated README with setup and usage instructions
- Clear prerequisites and estimated setup time
- Step-by-step deployment instructions
