# Core Platform

Solutions and utilities for core Databricks platform configurations, administration, and operations.

## Scope

This category covers:

- **Cluster Management** - Cluster policies, pool configurations, and autoscaling patterns
- **Identity & Access** - SCIM provisioning, group management, and access control automation
- **Platform Administration** - Workspace configuration, audit logging, and operational tooling
- **Networking** - Connectivity patterns, Private Link, and firewall configurations
- **Cost Management** - Tagging strategies, usage monitoring, and optimization scripts

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on adding new projects to this category.

Each project should include:
- A dedicated README with setup and usage instructions
- Any required configuration templates (e.g., `.tfvars.example`, `config.yaml.example`)
- Synthetic test data only (no customer data or PII)
