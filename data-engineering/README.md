# Data Engineering

Solutions for building ETL/ELT pipelines, data processing workflows, and ingestion patterns on Databricks.

## Scope

This category covers:

- **Delta Live Tables (DLT)** - Pipeline definitions, expectations, and CDC patterns
- **Structured Streaming** - Real-time ingestion from Kafka, Event Hubs, Kinesis, and other sources
- **Batch Processing** - Spark-based ETL patterns and optimization techniques
- **Data Ingestion** - Auto Loader configurations, file ingestion, and API-based data loading
- **Orchestration** - Databricks Workflows, job scheduling, and multi-task job patterns

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on adding new projects to this category.

Each project should include:
- A dedicated README with setup and usage instructions
- Sample notebooks or scripts with synthetic data
- Required cluster/compute configurations
